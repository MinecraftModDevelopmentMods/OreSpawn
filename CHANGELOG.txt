Version 4.0.6.110021

* Adopt target-qualified four-component versions so Minecraft and loader compatibility can be identified from the mod version.
* Port OreSpawn 4.0.6.110021 to Minecraft 1.10.2 and Forge 12.18.3.2511 using Java 8.
* Add deprecated OS1 and OS3 binary/configuration compatibility bridges for
  OreSpawn 1.1 and 3.2.2 consumers, translating plugins and registrations into one
  deduplicated OS4 scheduler with atomic backups and an idempotent report.
* Preserve 1.10 metadata block states, legacy dimension/biome selectors,
  weighted outputs, retrogen flags, vanilla suppression, and flat bedrock.
* Pin existing Mineralogy 3 worlds to OS4's Cyano engine before new chunks
  generate, snapshotting the legacy layer settings, exact ordered rock families,
  custom white/blacklists, and realistic coal behavior into the world profile.
* Write human-readable, reload-stable upgrade reports for consumed OS3/OS1 and
  Mineralogy 3 configuration, including preserved values and review warnings.
* Fix provider top and filler materials being generated one block below exposed ground.
* Apply underwater materials from the corrected ground and ceiling materials to roof undersides.
* Preserve trees, vegetation, structures and block entities by running surface replacement before late features.
* Preserve exact custom-biome rules and stagger close Stable Layers geome boundaries.
* Recalibrate Edge Detail and the managed vanilla-ore defaults for Minecraft 1.10.2.
* Apply vanilla-ore suppression at Forge's final standard event priority so
  later ordinary mod listeners cannot re-enable claimed vanilla ore features.
* Keep air-exposure inspection inside the active chunk so edge candidates do
  not load neighbouring chunks or depend on neighbour-generation order.
* Place dynamic fluid deposits through Forge's immutable world-write path so
  scheduled liquid ticks cannot retain a reusable generation cursor.
* Adapt geology, surfaces, ores, fluids, bedrock and static biome overlays to
  Forge 1.10 terrain events and one deduplicated IWorldGenerator fallback.
* Register the early surface/geology coordinator on Forge 1.10's actual event
  bus so it runs before later structures and vegetation while remaining safe
  across the Nether's duplicate decoration-pre events.
* Retain the OreSpawn biome registrar and deferred handles on Forge 1.10 registry events.
* Preserve vanilla springs in provider rocks through Forge's native terrain hooks.
* Restore reliable 1.10.2 editor backgrounds, tooltip clearing, translated cycle-button captions,
  and safe OreSpawn world-settings navigation.
* Preserve long host-block, host-tag and biome-filter values when reopening the ore and fluid editors.
* Package translations under Minecraft 1.10's required `ll_CC.lang` filename casing so editor
  captions load instead of displaying raw language keys.
* Existing chunks are not rewritten; the correction applies while generating new chunks.
