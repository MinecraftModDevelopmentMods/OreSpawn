Version 4.0.6

* Port OreSpawn 4.0.6 to Minecraft 1.13.2 and Forge 25.0.223 using Java 8.
* Fix provider top and filler materials being generated one block below exposed ground.
* Apply underwater materials from the corrected ground and ceiling materials to roof undersides.
* Preserve trees, vegetation, structures and block entities by running surface replacement before late features.
* Preserve exact custom-biome rules and stagger close Stable Layers geome boundaries.
* Recalibrate Edge Detail and the managed vanilla-ore defaults for Minecraft 1.13.2.
* Remove later-version basalt, Nether-gold, ancient-debris, and bamboo-jungle defaults from fresh 1.13.2 profiles.
* Support the single 1.13.2 dimension fluid while retaining later deep-aquifer profile fields as inactive data.
* Adapt static biome features and set-based biome providers to Forge 25 without changing provider or save contracts.
* Add an OreSpawn biome registrar so provider mods retain deferred biome declarations without Forge's later DeferredRegister API.
* Rebuild vanilla spring leaves with a Forge 25-native wrapper so provider rocks work without mutating unavailable platform fields.
* Create the public ore-pattern registry through Forge 25's native registry lifecycle and retain external registrations.
* Restore reliable 1.13.2 editor backgrounds, tooltip clearing, and translated cycle-button captions.
* Use Forge 25's native client rendering and navigation classes without platform-class shadows.
* Existing chunks are not rewritten; the correction applies while generating new chunks.
